# Nexus — редизайн v2 (передача в разработку)

Пакет описывает, как довести текущую десктоп-панель Nexus (Electron + React) до утверждённого редизайна. Сначала прочитай этот файл целиком, потом смотри макеты.

## Что в папке

| Путь | Что это | Как использовать |
| --- | --- | --- |
| `mockups/png/*.png` | Утверждённые экраны, 1400×900 | Визуальный эталон. Сверяй результат с ними |
| `mockups/html/*.html` | Те же экраны статичным HTML с inline-стилями | Точные отступы, размеры, цвета, тексты. Открываются в браузере |
| `mockups/dc-source/*.dc.html` | Исходники макетов из дизайн-холста | Только для справки: там видны данные и состояния (selected, focus, noOne) |
| `before/*.png` | Текущие экраны приложения | Что было, для сравнения |

Inline-стили из макетов **не копировать в разметку**. Переноси их в классы `styles.css` на существующих токенах. Новые токены описаны ниже.

## Общие правила

1. Ничего не ломаем: все текущие функции и API остаются. Меняются только UI и несколько фич, перечисленных ниже.
2. Без новых UI-библиотек. Иконки — inline SVG (stroke 1.8–2, 24×24), пути есть в `mockups/dc-source/Sidebar.dc.html`.
3. Светлая тема обязана работать для всего нового. Для каждого нового токена есть значение для `:root[data-theme="light"]` и блока `system`.
4. Шестиугольник (оранжевый, `--accent`) означает только одно: **нужно действие**. Простые счётчики пишутся текстом.
5. Сырые коды ошибок (`not_found` и т. п.) пользователю не показываются. Нужны понятный текст, кнопка «Повторить» и детали в tooltip.
6. Время:
   - относительное («12 мин назад», «ждёт 7 ч»), а абсолютное — в tooltip;
   - секунды нигде не показываются;
   - формат даты — `18.10.26, 21:33`.
7. Деструктивное действие или действие над 3+ людьми идёт через ConfirmDialog. Обратимое — через toast с «Отменить» (10 с).
8. Доступность:
   - настоящие `<button>`;
   - `aria-label` у кнопок-иконок;
   - `aria-pressed` у переключателей;
   - видимый фокус `--focus`;
   - все действия доступны с клавиатуры.

## Общие компоненты

### NavRail (меню слева) — `Sidebar.dc.html`
- Группы с подписями: **Каждый день** (Обзор, Пропуск, Голосовые, Модерация), **Сообщество** (Роли, Ивенты, Дни рождения, Экономика), **Данные** (Активность, Статистика, Журнал), **Сервер** (Настройки).
- У каждого пункта иконка 18 px. Активный пункт: фон `--raised`, слева полоска 3 px `--ink`, текст жирный.
- `ActionBadge` (шестиугольник) показывается только там, где ждут действия: Пропуск — число в очереди, Модерация — новые жалобы. Если 0, бейдж скрыт.
- Внизу «На смене»: аватары модераторов с открытой панелью (из SSE presence) и их имена. Под ними версия приложения из `app.getVersion()` с меткой «обновлено» или «доступно обновление».
- Пункты без прав скрыты, как и сейчас.

### Topbar — `Topbar.dc.html`
- Переключатель сервера: иконка сервера, название, выпадающий список.
- **CommandBar (Ctrl+K)**. Поле ищет участников и каналы, но умеет и команды: «мут @ник 1ч», «перенести Болталку в Мафию», «пропустить @ник девушка», «lockdown». Выпадающий список разбит на группы «Участники / Каналы / Команды». Enter выполняет команду, перед опасными командами показывается ConfirmDialog.
- **LockdownButton** имеет два состояния:
  - выключен — нейтральная кнопка с замком, обводка `--line`;
  - включён — красная заливка `--danger`, текст «Сервер закрыт».

  Клик в выключенном состоянии открывает ConfirmDialog с описанием того, что произойдёт.
- **BotStatus**. Точка зелёная, если всё в порядке. Жёлтая, если в диагностике есть проблемы (клик ведёт в Настройки → Диагностика). Красная, если нет связи.
- **Колокольчик уведомлений**. Последние 20 событий, оранжевая точка при непрочитанных.

### LockdownBanner
Пока Lockdown включён, полоса на всю ширину под Topbar видна на всех экранах. Текст: «Сервер закрыт с 21:24 · включил Flix · что именно сделано». Кнопки: «Изменить» и «Открыть сервер» (главная, красная). Пример — `V2Reports`.

### FilterChip, Chip, StatusPill
- FilterChip — скруглённая кнопка со счётчиком внутри. Активная: `--info-*`, `aria-pressed="true"`.
- Chip флага: маленький, жирный, цвет по уровню риска (`--danger-*` или `--warn-*`; нейтральный — `--raised` + `--text-3`).
- StatusPill — обводка в цвет статуса. Варианты: «новая · никто не взял» (accent), «в работе · Flix» (ink), «Смотрит Kira» (presence, с точкой).

### SelectionBar (групповые действия)
Один компонент на Пропуск, Голосовые, Участники и Роли.
- Появляется, если выбран хотя бы 1 элемент. Слева «Выбрано N» и до трёх имён, справа кнопки действий, в конце «Снять выделение» (Esc).
- В Пропуске это полоса над таблицей, в Голосовых — плавающая панель внизу экрана.
- Механика выделения одна для всех: клик, Ctrl-клик, Shift-клик, рамка мышью, Ctrl+A, Esc.

### TaskTray (фоновые задачи)
Плавает справа внизу, над SelectionBar. В нём каждая массовая операция: перенос, массовая выдача или снятие роли, массовый мут.
- Название, «5 / 6», прогресс-бар, строка с первой ошибкой («Bob вышел из голоса — не перенесён»), ссылки «Отменить всё» и «Повторить для неудачных».
- Через 5 с после завершения сворачивается в toast.
- Полосу прогресса из экрана Ролей заменить на TaskTray.

### OverflowMenu «⋯»
Кнопка 32–34 px с `aria-label`, перечисляющим скрытые действия. В меню сначала идут обычные пункты, затем разделитель, затем отклоняющие или опасные. Пример раскрытого меню — `V2Reports`.

### MemberDrawer (карточка участника) — `V2Member`
- Ширина 470 px, остальной экран затемнён. Esc или крестик закрывают её.
- **Закреплённая шапка:**
  - аватар 56, имя, @handle;
  - кнопка с ID, которая копирует его по клику (моноширинный шрифт);
  - строка статуса голоса;
  - быстрые действия: главное контекстное (например, «Вкл. микро», если микрофон выключен сервером; иначе «Мут»), затем «Переместить», «Мут ▾», «Варн» и «⋯» (отключить от голоса, сменить ник, кик, бан).
- **Вкладки:** Обзор · Модерация (число варнов) · Экономика · История. Скроллится только тело.
- **Вкладка «Обзор»:**
  - 4 факта в сетке 2×2;
  - роли чипами с «×»; если роль выше роли бота, вместо «×» замок и tooltip «Выше роли бота — снять можно только в Discord»;
  - «+ роль или пресет»;
  - сводка экономики с прогрессом в цифрах;
  - заметки модераторов.

### Avatar
Настоящий аватар из Discord CDN (`size=64`). Если его нет, показываются инициалы на цвете, который вычисляется из ID. Дефолтную иконку Discord не использовать: сейчас все аватары одинаковые.

### Состояния
- **EmptyState**: иконка, одна строка, при необходимости действие.
- **ErrorState**: «Не удалось загрузить варны», кнопка «Повторить», код в tooltip.
- **Skeleton** при загрузке, без «прыгания» вёрстки.

### Модерация → Жалобы, Lockdown включён — `V2Reports.png`

## Экраны без макета — применить те же правила

- **Активность:**
  - период применяется к графикам (сейчас «Неделя», а подпись говорит «за 30 дней»);
  - у графиков нужны ось Y с 3 делениями и tooltip по наведению;
  - в топе нужна колонка «Очки» при режиме «Вместе», и сортировать по ней.
- **Экономика:**
  - у прогресса цифры в tooltip;
  - серое имя получает tooltip «Покинул сервер — счёт обезличен через N дн.»;
  - длинную формулу уровней убрать в «?»;
  - в форме настроек нужна закреплённая полоса «Сохранить / Отменить»;
  - предупреждение о двойном начислении сделать заметным блоком (warn).
- **Роли:**
  - сразу открывать первую роль со списком владельцев, без заглушки «Выберите роль»;
  - массовые операции пускать через TaskTray.
- **Дни рождения:**
  - в календаре показывать имена в клетках;
  - в списке оставить главное действие + «⋯»;
  - убрать отсылку к «старой веб-панели»: перенести время и каналы в Настройки → Дни рождения.
- **Журнал:**
  - формат «кто → кому», группировка по дням, относительное время;
  - строка открывает детали; у обратимых действий кнопка «Отменить»;
  - когда автор неизвестен, писать «неизвестно», а не «—».
- **Статистика:** нули показывать как «0» цветом `--muted-2`, а не «·»; добавить график решений по дням.
- **Настройки:**
  - выровнять сетку формы (поле «Парень» сейчас выше остальных);
  - подсказку «берётся из переменных окружения Azure» заменить на явное состояние: «Сейчас: из Azure. После сохранения — из настроек сервера»;
  - в Диагностике у каждого красного пункта нужна кнопка «Как исправить» (ссылка или инструкция).

## Что нужно со стороны бота и API

- **Presence:** кто из модераторов открыт в панели и какую карточку смотрит. Рассылать по SSE, держать в памяти.
- **История для флагов:** число прошлых киков из очереди по ID пользователя и время ожидания — из журнала или отдельной коллекции.
- **Контекст жалобы:** активные варны и наказания нарушителя за последние 30 дней.
- **Шаблоны наказаний:** CRUD, хранение на сервер (guildId).
- **Фоновые задачи:** `POST` запускает задачу и возвращает `taskId`, прогресс и ошибки по каждому участнику идут через SSE, плюс endpoints отмены и повтора для неудачных.
- **Lockdown:** состояние, кто и когда включил, что именно сделано — нужно для баннера.
