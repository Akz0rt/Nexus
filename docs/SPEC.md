# Админ-панель Discord: спецификация

Oct 16, 2026 · @Flix

## Цель, роли и принципы

Панель — веб-интерфейс к Birthday-Bot, в котором модераторы за один-два клика делают то, что в Discord требует десятка действий: пропуск новичков, групповые действия в голосовых, муты и баны. Бот остаётся единственным, кто действует на сервере; панель показывает состояние и отправляет ему команды.

Принципы:

- **Discord — источник истины.** Статус новичка = наличие роли @АНверефи, голосовые = реальные voice states. Если кто-то сделал действие вручную в Discord, панель это подхватит.
- **Всё в реальном времени у всех.** Действие одного модератора сразу видно остальным.
- **Каждое действие — в журнал** с автором, целью, временем и источником (панель, Discord, бот).
- **Опасное — с подтверждением.** Бан, кик, любое действие над 3+ людьми — модальное окно с итогом.
- **Права проверяет сервер, а не интерфейс.** Кнопка скрыта, если права нет, но API всё равно перепроверяет.
- **Групповые действия везде работают одинаково:** клик, Ctrl-клик, Shift-клик, рамка, Esc.

| Роль в панели | Кому выдаётся | Что доступно |
| --- | --- | --- |
| Администрация | все, у кого есть админская роль на сервере | все экраны и действия; бан — если в Discord есть право Ban Members. Настройки бота и Lockdown — только ролям с галочкой «Старшая администрация» |
| Участник | все верифицированные (этап 5) | свой профиль: день рождения, роли по интересам, жалоба |

Роль в панели определяется по ролям в Discord; соответствие настраивается на экране «Настройки».

## Архитектура

Бот и API живут в одном Node.js-процессе на Azure App Service, как и сейчас; панель никогда не видит токен бота.

Кнопка в панели и кнопка в Discord вызывают одну и ту же функцию модуля; результат уходит в журнал и рассылается всем открытым панелям через SSE.

- **Intents:** добавить GuildMembers (привилегированный, включается в Developer Portal); GuildVoiceStates уже есть.
- **Права бота:** Manage Roles, Move Members, Mute/Deafen Members, Moderate Members, Kick, Ban, Manage Messages, View Audit Log; роль бота выше @АНверефи и ролей пола.
- **Вход:** Discord OAuth (scope identify) вместо нынешнего Basic Auth; роль в панели берётся из ролей участника на сервере.
- **Групповые действия:** один вызов Discord API на человека, с учётом rate limit, итог «успешно / не удалось» по каждому.
- **Azure:** Always On включён, ровно один экземпляр (два = два бота на одном токене).
- **Новые контейнеры Cosmos DB:** audit\_log, warnings, member\_notes, voice\_squads, queue\_cards, panel\_sessions.

**Формат приложения — PWA.** Панель пишется на React + Vite, собирается в статические файлы и отдаётся тем же Express на уже оплаченном App Service. Из браузера её можно «Установить»: появляется иконка на рабочем столе и в меню «Пуск» или на телефоне, отдельное окно без адресной строки, push-уведомления. Обновления приходят сами с каждым деплоем.

| Вариант | Плюсы | Минусы |
| --- | --- | --- |
| PWA (выбран) | один код для ПК и телефона, без доп. хостинга и установщиков | нет трея и глобальных горячих клавиш |
| Tauri (позже, если нужно) | настоящий .exe около 10 МБ, трей, автозапуск; тот же React-код | сборка и подпись под каждую ОС |
| Electron | то же, что Tauri | установщик около 150 МБ, больше памяти |

Расходы держим в текущих рамках: один App Service, Cosmos DB в режиме serverless с TTL, SSE вместо опроса раз в N секунд.

**Несколько серверов.** Используем на одном, но закладываем сразу — потом доделывать дороже:

- guildId — ключ раздела во всех контейнерах Cosmos DB и в каждом запросе API.
- Настройки (роли, каналы, модули) хранятся на сервер в БД, а не в переменных окружения; GUILD\_ID остаётся только как сервер по умолчанию.
- В шапке панели — переключатель сервера: в нём те серверы, где есть бот и где ты в администрации; кнопка «Добавить бота на сервер».
- Slash-команды регистрируются глобально, а не на один сервер.

## Общий каркас интерфейса

На всех экранах одинаковы меню слева, шапка с поиском, уведомления и боковая карточка участника, которая открывается кликом по любому нику.

| Элемент | Что делает |
| --- | --- |
| Меню слева | Обзор, Пропуск (счётчик очереди), Голосовые, Участники, Модерация (счётчик жалоб), Роли, Дни рождения, Активность, Журнал, Настройки. Пункты без права доступа скрыты |
| Блок «На смене» внизу меню | кто из модераторов сейчас открыл панель |
| Поиск в шапке | ник, серверный ник, ID или @упоминание → выпадающий список → Enter открывает карточку. Горячая клавиша Ctrl+K |
| Кнопка Lockdown | закрывает сервер: пауза инвайтов + slowmode в стартовых каналах. Повторное нажатие снимает. Только старшая администрация, с подтверждением |
| Индикатор связи | зелёный — бот онлайн, жёлтый — переподключение, красный — бот недоступен (действия блокируются) |
| Колокольчик | последние 20 уведомлений: новичок зашёл, жалоба, подозрение на рейд, ошибка бота |
| Аватар модератора | свои настройки: звук уведомлений вкл/выкл, браузерные push, тема, выход |
| Тосты | всплывающие уведомления на 5 сек; у обратимых действий кнопка «Отменить» |
| Окно подтверждения | «Забанить 3 чел.?» + список имён + причина. Enter — да, Esc — отмена |
| Итог группового действия | «Перемещено 7 из 8, Bob вышел из голоса» — с кнопкой «Повторить для неудачных» |

Правила выделения, одинаковые в списках и на доске голосовых:

- Клик — выбрать/снять одного.
- Ctrl-клик — то же, не сбрасывая остальных; Shift-клик — диапазон в списке.
- Рамка по пустому месту — выделить всех, кого задела; с Shift — добавить к выделенным.
- Ctrl+A — всех в текущем списке или канале; Esc — снять выделение.
- Длинное нажатие на телефоне — режим выбора, дальше тапами.
- При выборе хотя бы одного появляется панель действий с счётчиком «Выбрано: N».

На телефоне меню уходит в нижнюю панель (5 главных пунктов + «Ещё»), карточка открывается на весь экран.

## Экран «Обзор»

Стартовая страница: за пять секунд понять, есть ли работа, и сделать самое частое без перехода на другие экраны. Все блоки — сокращённые версии своих экранов с ссылкой «Все →».

| Блок | Что показывает | Действия |
| --- | --- | --- |
| Плитки | Ждут пропуска · Пропущено сегодня · В голосовых · Активные муты · Новые жалобы | клик по плитке → соответствующий экран с фильтром |
| Очередь на пропуск | первые 5 карточек | Парень · Девушка · Кик, как на полном экране |
| Голосовые | компактная доска каналов, где кто-то есть | выделение и перетаскивание, панель действий |
| Журнал | последние 10 событий | клик по нику → карточка |
| Быстрые действия | набор кнопок, настраиваемый в Настройках | Slowmode в канале · Очистить N сообщений · Объявление от бота · Разбить голосовой на команды |
| Ближайшие дни рождения | сегодня и следующие 7 дней | «Поздравить сейчас» для сегодняшних |

Сами плитки и блоки можно скрывать и переставлять — настройка сохраняется для каждого модератора отдельно (этап 4).

## Экран «Пропуск новичков»

В очереди все, у кого есть роль @АНверефи; пропуск снимает её и выдаёт роль пола одним действием. Карточка закрывается у всех, как только роль снята — из панели, кнопкой в Discord или вручную.

Боты в очередь не попадают. У каждого человека роль пола обязательна, третьего варианта при пропуске нет.

Кто вешает @АНверефи: сейчас — сторонний бот верификации, наш только читает роль и при пропуске меняет её на роль пола. Когда сторонний бот отключат, в Настройках включается галочка «Выдавать @АНверефи при входе», и роль вешает наш бот (по умолчанию выключена). При каждом запуске бот пересобирает очередь по всем, у кого есть роль, — никто не потеряется, даже если зашёл, пока бот перезапускался.

Жизненный цикл новичка:

1. Человек заходит → пока что @АНверефи вешает другой бот; наш бот видит появление роли (guildMemberUpdate), считает флаги риска, создаёт карточку в панели и в канале модераторов, шлёт уведомление.
2. Модератор открывает карточку → у остальных на ней пометка «Смотрит Kira» (без блокировки).
3. Пропуск: снять @АНверефи + выдать роль пола + (опционально) приветствие в общем чате. Или отказ: кик или бан с причиной.
4. Карточка уходит во вкладку «Обработаны» с автором и временем; карточка в Discord редактируется: «Пропущен · Kira».
5. Если два модератора нажали одновременно, сервер выполняет первое нажатие, второй видит «Уже пропустила Kira · Девушка».

| Элемент | Что делает |
| --- | --- |
| Вкладки | Ждут · Обработаны сегодня · Отклонены (кикнуты/забанены) |
| Сортировка | сначала старые (по умолчанию) · сначала новые · сначала с флагами |
| Фильтр | только с флагами · по инвайту · зашли больше N часов назад |
| Карточка: шапка | аватар, ник, серверный ник, ID (клик — скопировать) |
| Карточка: данные | возраст аккаунта, когда зашёл, чей инвайт, сколько раз заходил раньше, был ли раньше наказан |
| Карточка: флаги | «Аккаунт младше 7 дней», «Нет аватара», «Ник похож на забаненного», «Вошёл в волне рейда», «Ранее был кикнут». Пороги — в Настройках |
| Карточка: заметка | поле для модераторов, сохраняется в истории участника |
| Кнопка «Парень» / «Девушка» | снять @АНверефи + выдать MALE\_ROLE\_ID / FEMALE\_ROLE\_ID. Горячие клавиши M / F на выбранной карточке |
| Кнопка «Доп. роли» | перед пропуском отметить пресет или отдельные роли (например, регион) |
| Кнопка «Задать вопрос» | бот упоминает новичка в стартовом канале с текстом из шаблона («Расскажи, откуда узнал о сервере») |
| Кнопка «Отказать» (список) | Кикнуть с сообщением · Забанить · Оставить в очереди с пометкой «Перепроверить» |
| Групповой выбор | отметить несколько карточек → Парень · Девушка · Кикнуть всех (полезно при рейде) |
| Отмена | 10 секунд после пропуска — «Отменить» вернёт @АНверефи и снимет роль пола; во вкладке «Обработаны» — «Вернуть в очередь» |
| Редактировать пол | у обработанных: поменять роль пола, если ошиблись |

Волна рейда: если за минуту зашло больше порога (по умолчанию 10), над очередью появляется красная плашка с кнопками «Включить Lockdown» и «Выделить всех из волны».

## Экран «Голосовые каналы»

Доска всех голосовых каналов, сгруппированных по категориям сервера: выделяешь людей в любых каналах и делаешь действие сразу над всеми. Действует только на тех, кто уже в голосе: Discord не умеет подключить человека к каналу без него.

Плитка участника показывает: аватар, ник, сам выключил микро/звук, выключен сервером (красная иконка), стримит, камера, сколько времени в канале, значок модератора. Наведение — роли и активные наказания.

**Панель действий над выделенными**

| Кнопка | Что делает |
| --- | --- |
| Переместить в… | список каналов с поиском → перенос. То же делает перетаскивание выделенных на канал |
| Выключить / включить микро | server mute, действует во всех каналах, пока не снят |
| Заглушить / вернуть звук | server deafen |
| Отключить от голоса | выкидывает из голосового, но не с сервера |
| Тайм-аут… | срок 10 мин / 1 ч / 6 ч / 1 д / 7 д + причина из шаблона |
| Роль… | выдать или снять роль всем выделенным (например, «Участник ивента») |
| Сохранить как состав | запомнить группу под именем («Мафия, пятница») |
| Открыть карточку | если выделен один |
| Сбросить | снять выделение (Esc) |
| Отменить перемещение | в тосте после переноса: вернуть каждого в его прежний канал |

**Меню канала (кнопка «…» в заголовке)**

| Пункт | Что делает |
| --- | --- |
| Выбрать всех | выделить всех в канале |
| Собрать сюда | перенести сюда всех из отмеченных каналов или из целой категории |
| Перенести весь канал в… | всех из этого канала — в другой |
| Замутить всех, кроме… | ведущий остаётся с микрофоном; «Размутить всех» — обратно |
| Разбить на команды | выбрать N каналов → случайно или расставить вручную → «Разослать»; потом «Собрать обратно» |
| Закрыть / открыть | запретить вход @everyone (например, на время ивента) |
| Лимит и название | поменять лимит участников и имя канала |

**Составы** — боковой список сохранённых групп. «Выделить» отмечает на доске тех, кто сейчас в голосе; «Собрать» переносит их в канал, а тем, кого нет в голосе, бот пишет приглашение; «Изменить» и «Удалить» — как обычно.

Фильтр сверху доски: скрыть пустые каналы · только категория X · поиск по нику (подсвечивает найденного). Для переноса боту нужны Move Members и право Connect в целевом канале.

## Экран «Модерация»

Все действующие наказания и входящие жалобы в одном месте; четыре вкладки.

| Вкладка | Что в ней | Кнопки |
| --- | --- | --- |
| Активные наказания | муты и временные баны с таймером «осталось 42 мин», кто выдал, причина | Снять · Продлить · Открыть карточку; группово — «Снять все выделенные» |
| Баны | список банов сервера с поиском, причиной, автором и датой | Разбанить (с подтверждением) · Забанить по ID (человека нет на сервере) |
| Варны | все предупреждения, счётчик на участника, срок сгорания | Выдать варн · Снять · Правила эскалации |
| Жалобы | очередь жалоб от участников: на кого, ссылка на сообщение, текст, статус | Взять себе · Наказать (открывает карточку) · Отклонить · Ответить заявителю в ЛС |

Правила эскалации варнов (редактирует старшая администрация), пример по умолчанию:

| Активных варнов | Автоматическое действие |
| --- | --- |
| 2 | тайм-аут 1 ч |
| 3 | тайм-аут 1 д |
| 5 | уведомление старшей администрации с кнопкой «Забанить» |

Варн сгорает через 30 дней. Шаблоны причин (флуд, оскорбления, реклама, твинк, скам) общие для мутов, варнов, киков и банов; редактируются в Настройках. Каждое наказание может сопровождаться сообщением наказанному в ЛС и записью в канал логов.

## Экран «Роли и пресеты»

Массовая работа с ролями и готовые наборы ролей, чтобы не кликать по одной.

| Блок | Что делает |
| --- | --- |
| Список ролей | все роли в порядке иерархии, цвет, число участников; роли выше роли бота помечены «бот не может выдавать» |
| Клик по роли | список её владельцев → «Снять у выделенных», «Снять у всех» |
| Массовая выдача | роль + фильтр (всем, у кого есть X; всем в голосовом Y) → предпросмотр «затронет 47 чел.» → подтвердить; прогресс-бар |
| Пресеты | именованный набор ролей («Ивентер», «Хелпер»); Создать · Изменить · Удалить; применяется из карточки и в пропуске |
| Временные роли | выдать роль на N часов/дней — бот снимет сам; список с оставшимся временем |
| Роли по интересам (этап 5) | конструктор сообщения с кнопками: канал, текст, список ролей, одна или несколько → «Опубликовать» / «Обновить» |

Роли сами по себе (создание, права, цвет) редактируются в Discord, не в панели — так меньше шансов сломать права сервера.

## Экраны «Дни рождения» и «Активность»

Это нынешние функции бота и текущей панели (вкладки «Сервер», «Настройки», «AI Чат»), перенесённые в новую структуру; новое помечено «новое».

**Дни рождения**

| Элемент | Что делает |
| --- | --- |
| Ближайшие | сегодня · 7 дней · 30 дней; «Поздравить сейчас», «Пропустить в этом году» (новое) |
| Все дни рождения | таблица с поиском; Добавить за участника · Изменить · Удалить (новое: сейчас только через /birthday-set и AI) |
| Календарь | месяц с аватарками по дням (новое) |
| Текст поздравления | шаблон с переменными {user}, {age}; разные для парней и девушек; переключатель «Генерировать через AI»; «Предпросмотр» (новое) |
| Настройки | время проверки (CHECK\_TIME), часовой пояс, каналы объявлений и поздравлений, роль именинника |

**Активность**

| Элемент | Что делает |
| --- | --- |
| Период и режим | час / день / неделя / месяц; текст / голос / вместе; учитывать игры |
| Топ участников | рейтинг за период, клик → карточка |
| График сервера | сообщения и часы в голосе по дням, входы и выходы, пропущенные новички (новое) |
| Статистика модераторов | кто сколько пропустил, замутил, разобрал жалоб; среднее время ожидания в очереди (новое) |
| Баннер сервера | режим самый активный / именинник / случайный / нет, предпросмотр, «Обновить пользователя» |
| Синхронизация | статус сбора активности (activity-sync-status) |

AI-чат из текущей панели остаётся как выдвижная панель справа, доступная с любого экрана.

## Экран «Журнал действий»

Одна таблица всех действий на сервере, новые сверху; сюда пишут панель, бот и ручные действия в Discord (из audit log).

| Элемент | Что делает |
| --- | --- |
| Колонки | время · кто · действие · над кем (один или «7 чел.» с раскрытием) · причина · источник (панель / Discord / бот / авто) |
| Фильтры | тип действия · модератор · участник · период · источник |
| Отменить | для обратимых действий: пропуск, выдача роли, мут, перемещение (если люди ещё в голосе) |
| Экспорт | CSV за выбранный период с текущими фильтрами |
| Дублирование в Discord | каждая запись уходит ещё и в канал логов модерации (выбирается в Настройках) |

Записи хранятся 30 дней и удаляются автоматически (TTL в Cosmos DB); экспорт в CSV — если нужно сохранить дольше.

Удалённые и отредактированные сообщения (этап 4): бот включает intent MessageContent, держит свежие сообщения в памяти и пишет в журнал только те, что удалили или изменили. Это дёшево: intent бесплатен и включается в Developer Portal без верификации, пока бот на меньше чем 100 серверах, а в БД попадает лишь малая доля сообщений.

## Экран «Настройки бота»

Доступен только старшей администрации. Все настройки — отдельно для каждого сервера. Всё хранится в Cosmos DB, как сейчас (SettingsService); секреты по-прежнему только в Azure App Settings и показываются звёздочками.

| Раздел | Настройки |
| --- | --- |
| Доступ к панели | какие роли Discord считаются администрацией и у каких из них есть галочка «Настройки и Lockdown»; список тех, кто заходил, и когда |
| Роли сервера | @АНверефи (UNVERIFIED\_ROLE\_ID, новое), Парень (MALE\_ROLE\_ID), Девушка (FEMALE\_ROLE\_ID), именинник — выбор из списка ролей, а не ввод ID |
| Каналы | очередь пропуска для модераторов, логи модерации, приветствие, стартовый канал новичков, дни рождения, AI |
| Пропуск | текст приветствия вкл/выкл, шаблон «Задать вопрос», сообщение при кике, пороги флагов (возраст аккаунта в днях), «Выдавать @АНверефи при входе» (выкл, пока работает сторонний бот) |
| Анти-рейд | порог «N входов за M секунд», что делать: только уведомить / включить Lockdown самостоятельно |
| Модерация | шаблоны причин, правила эскалации варнов, срок сгорания, сообщения в ЛС при наказании |
| Модули | вкл/выкл: дни рождения, AI, активность, пропуск, анти-рейд, жалобы |
| AI | модель (OPENAI\_MODEL), длина истории (AI\_MAX\_HISTORY) |
| Диагностика | автопроверка с зелёными/красными пунктами: включены ли intents, есть ли у бота Manage Roles / Move Members / Moderate Members / Ban / Kick, стоит ли роль бота выше @АНверефи и ролей пола, доступна ли БД; аптайм и пинг |

Кнопка «Сохранить» применяет без перезапуска бота там, где это возможно; сейчас любое сохранение перезапускает веб-приложение через Azure Management API.

## Функции в самом Discord

Самое частое должно работать и без панели — с телефона, не выходя из Discord. Логика у кнопок и панели общая.

| Функция | Как выглядит |
| --- | --- |
| Карточка новичка | embed в канале модераторов с данными и флагами + кнопки Парень · Девушка · Кик · «Открыть в панели»; после решения кнопки исчезают, появляется «Пропущен · Kira · 21:06» |
| Контекстное меню участника | ПКМ по человеку → Приложения → «Пропустить: парень», «Пропустить: девушка», «Варн…», «Карточка» |
| /move | из канала X (или моего) в канал Y; опции «только @роль», «состав» |
| /voice mute-all, /voice split | замутить всех в моём канале, кроме меня; разбить на N команд |
| /warn, /mute, /unmute | с автодополнением шаблонов причин и сроков |
| /panel | личная (ephemeral) ссылка на панель |
| Жалоба (этап 5) | ПКМ по сообщению → Приложения → «Пожаловаться» → окно с причиной; уходит во вкладку «Жалобы» |
| Стартовый канал (этап 5) | сообщение бота с кнопкой «Заполнить анкету» (пол, откуда узнал, день рождения) — ответы попадают в карточку пропуска |

Уже есть и остаются: /birthday-set, /birthday, /birthdays-coming, AI по @упоминанию.

## Этапы разработки

Каждый этап сам по себе приносит пользу; панель строится поверх уже работающей логики бота.

1. **Основа и пропуск в Discord.** Intent GuildMembers, UNVERIFIED\_ROLE\_ID, модульная структура бота, карточка новичка с кнопками в канале модераторов, журнал действий в Cosmos DB, канал логов. Все данные и настройки сразу с guildId.
2. **Новая панель: каркас.** Вход через Discord OAuth вместо Basic Auth, роли доступа, realtime-канал (SSE), меню, поиск, карточка участника, экраны «Пропуск» и «Журнал». Перенос старых вкладок в «Дни рождения», «Активность», «Настройки».
3. **Голосовые и модерация.** Доска голосовых с выделением рамкой и перетаскиванием, групповые действия, составы, экран «Модерация» (без жалоб), варны и эскалация, slash-команды /move, /voice, /warn, /mute.
4. **Расширения.** Анти-рейд и Lockdown, роли и пресеты, временные роли, настраиваемый «Обзор», статистика модераторов, диагностика, лог удалённых и изменённых сообщений.
5. **Для участников.** Анкета при входе, жалобы, роли по интересам, личный профиль в панели, ивенты с записью.

## Решения и открытые вопросы

| Вопрос | Решение |
| --- | --- |
| Третий вариант при пропуске | не нужен: у каждого человека есть роль пола, боты идут мимо очереди |
| Уровень «Верификатор» | не нужен: либо участник, либо администрация |
| Лог удалённых сообщений | делаем на этапе 4 — фича дешёвая |
| Срок хранения журнала | 30 дней, автоудаление |
| Формат приложения | PWA на React + Vite в том же App Service; Tauri — позже, если понадобится .exe |
| Несколько серверов | закладываем с самого начала, используем на одном |

Кто вешает @АНверефи: пока сторонний бот, наш только читает и меняет на роль пола; после отключения стороннего — включаем выдачу роли в нашем.

- [ ] Когда сторонний бот верификации отключат — включить «Выдавать @АНверефи при входе» в Настройках.
