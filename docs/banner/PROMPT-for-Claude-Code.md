```
В docs/banner/ лежит утверждённый дизайн нового баннера сервера и экрана «Баннер» в панели.
Прочитай docs/banner/README.md целиком и посмотри все PNG в docs/banner/mockups/png.

ACTIVITY_CALC_MODE, /api/featured-user, /api/server-banner-settings, ActivityService)
и опиши, как новый баннер ляжет поверх неё.

Потом покажи план по разделу «Порядок работ»: какие файлы меняешь, какие пакеты
добавляешь (satori, @resvg/resvg-js, ffmpeg-static, шрифт), какие эндпоинты и настройки.
Жди подтверждения. Начинаем с шагов 1–2: настройки и слой карточки, с тестовыми
рендерами всех 12 вариантов в PNG, которые сравним с mockups/png.

Текущую GIF я загружу через экран «Баннер», когда он будет готов. До этого используй
для тестов любой GIF 960×540.
```
